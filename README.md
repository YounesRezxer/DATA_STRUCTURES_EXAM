## کامپایل کدها

کدهای C++ را می‌توانید با یک کامپایلر سازگار با C++11 یا جدیدتر اجرا کنید. برای نمونه:

```bash
g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o app
./app
```

هر قطعه‌کد مستقل است؛ آن را در فایل جداگانه‌ای مانند `main.cpp` قرار دهید. کدهای آموزشی برای فهم الگوریتم نوشته شده‌اند و لزوماً جایگزین پیاده‌سازی production-ready نیستند.
