پاسخ سؤال ۱

در حلقه بیرونی، i توان‌های 2 را می‌گیرد؛ بنابراین تعداد تکرارهای آن Θ(log n) است. برای هر مقدار i، حلقه داخلی تقریباً n/i بار اجرا می‌شود.

پس مجموع اجراها برابر است با:

T(n) = Σ (n / 2^k),  k = 0 تا ⌊log₂n⌋

این یک مجموع هندسی با مقدار کمتر از 2n است؛ بنابراین T(n)=Θ(n).

پاسخ سؤال ۶

Node* reverseList(Node* head) {
    Node* prev = nullptr;
    Node* current = head;

    while (current != nullptr) {
        Node* nextNode = current->next;
        current->next = prev;
        prev = current;
        current = nextNode;
    }
    return prev;
}

در هر مرحله، nextNode ادامه لیست را نگه می‌دارد، پیوند current معکوس می‌شود، سپس prev و current جلو می‌روند. هر گره یک‌بار پردازش می‌شود؛ زمان O(n) و فضای کمکی O(1) است.

پاسخ سؤال ۸

Selection Sort در هر گذر کوچک‌ترین عنصر بخش مرتب‌نشده را پیدا می‌کند. آرایه پس از گذرها:

شروع: [29, 10, 14, 37, 13, 25, 8]
1:     [8, 10, 14, 37, 13, 25, 29]
2:     [8, 10, 14, 37, 13, 25, 29]
3:     [8, 10, 13, 37, 14, 25, 29]
4:     [8, 10, 13, 14, 37, 25, 29]
5:     [8, 10, 13, 14, 25, 37, 29]
6:     [8, 10, 13, 14, 25, 29, 37]

برای n=7 تعداد مقایسه‌های Selection Sort برابر 7×6÷2=21 است. اگر جابه‌جایی فقط در صورت متفاوت بودن اندیس انجام شود، 5 جابه‌جایی واقعی داریم. هر دو الگوریتم در حالت متوسط و بد O(n²) هستند؛ Insertion Sort در حالت بهترین O(n) است، اما Selection Sort همچنان O(n²) می‌ماند.

پاسخ سؤال ۱۰

bool secondLargest(const vector<int>& a, int& answer) {
    if (a.size() < 2) return false;

    int largest = 0, second = 0;
    bool hasLargest = false, hasSecond = false;

    for (int x : a) {
        if (!hasLargest || x > largest) {
            if (hasLargest) {
                second = largest;
                hasSecond = true;
            }
            largest = x;
            hasLargest = true;
        } else if (x < largest && (!hasSecond || x > second)) {
            second = x;
            hasSecond = true;
        }
    }

    if (!hasSecond) return false;
    answer = second;
    return true;
}

هر عنصر یک‌بار بررسی می‌شود؛ بنابراین زمان O(n) و فضای کمکی O(1) است. متغیرهای منطقی، حالت نبودن مقدار دوم را مشخص می‌کنند؛ در نتیجه به مقداردهی اولیه با INT_MIN وابسته نیستیم.
