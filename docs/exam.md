# آزمون شماره ۳ ساختمان داده — تشریحی و دشوار

- **سطح:** دشوار / استادی
- **زمان پیشنهادی:** ۱۲۰ دقیقه
- **نمره کل:** ۲۰
- **تعداد سؤال:** ۱۰
- **زبان کدنویسی:** C++

## دستورالعمل

1. تمام پاسخ‌ها باید همراه با استدلال و مراحل حل باشند.
2. در مسائل محاسباتی، فرمول و مراحل ساده‌سازی را بنویسید.
3. در سؤال‌های کدنویسی، کد C++ کامل و قابل‌فهم ارائه دهید.
4. در مرتب‌سازی‌ها، آرایه را پس از هر گذر یا مرحله نشان دهید.
5. هر سؤال ۲ نمره دارد.

---

## سؤال ۱ — تحلیل پیچیدگی الگوریتم‌ها (۲ نمره)

الگوریتم زیر را در نظر بگیرید:

```cpp
int count = 0;

for (int i = 1; i <= n; i *= 2) {
    for (int j = 1; j <= n; j += i) {
        for (int k = 1; k <= j; k++) {
            count++;
        }
    }
}
```

الف) رابطه مجموعی تعداد اجرای دستور `count++` را برحسب \(n\) بنویسید.  
ب) مرتبه زمانی الگوریتم را با استدلال ریاضی تعیین کنید.  
ج) آیا می‌توان پیچیدگی این الگوریتم را مستقیماً برابر حاصل‌ضرب تعداد تکرار سه حلقه دانست؟ چرا؟

## سؤال ۲ — آرایه‌ها و آدرس‌دهی (۲ نمره)

آرایه‌ی دوبعدی زیر در حافظه به روش Row Major ذخیره شده است:

```cpp
int A[5][8];
```

فرض کنید آدرس پایه آرایه برابر 2000 و اندازه هر عنصر 4 بایت است.

الف) فرمول عمومی محاسبه آدرس `A[i][j]` را استخراج کنید.  
ب) آدرس عنصر `A[3][6]` را محاسبه کنید.  
ج) اگر آرایه به روش Column Major ذخیره می‌شد، آدرس همین عنصر چقدر بود؟  
د) توضیح دهید چرا دسترسی به یک عنصر مشخص در آرایه پیچیدگی زمانی \(O(1)\) دارد.

## سؤال ۳ — جست‌وجوی دودویی (۲ نمره)

آرایه مرتب‌شده زیر را در نظر بگیرید:

```cpp
int A[10] = {3, 7, 11, 15, 19, 23, 27, 31, 35, 39};
```

می‌خواهیم عدد 22 را با روش Binary Search جست‌وجو کنیم.

الف) تمام مراحل جست‌وجو را با ذکر مقادیر `low`، `high` و `mid` بنویسید.  
ب) تعداد مقایسه‌ها را مشخص کنید.  
ج) اگر همین جست‌وجو با Linear Search انجام شود، تعداد مقایسه‌ها چقدر خواهد بود؟  
د) پیچیدگی زمانی هر دو روش را در بهترین و بدترین حالت مقایسه کنید.

## سؤال ۴ — پشته و ارزیابی Postfix (۲ نمره)

عبارت پسوندی زیر را با استفاده از Stack ارزیابی کنید:

```text
8 2 3 * + 12 4 / - 5 *
```

الف) عبارت را مرحله‌به‌مرحله ارزیابی کنید.  
ب) وضعیت پشته را پس از هر عملیات نشان دهید.  
ج) نتیجه نهایی را به دست آورید.  
د) الگوریتم ارزیابی عبارت Postfix را با C++ پیاده‌سازی کنید. پیاده‌سازی باید توکن‌های چندرقمی را نیز پشتیبانی کند.

## سؤال ۵ — صف حلقوی (۲ نمره)

یک صف حلقوی با ظرفیت ۶ خانه داریم. در ابتدا صف خالی است. عملیات زیر به ترتیب اجرا می‌شوند:

```text
Enqueue(10)
Enqueue(20)
Enqueue(30)
Enqueue(40)
Dequeue()
Dequeue()
Enqueue(50)
Enqueue(60)
Enqueue(70)
Enqueue(80)
```

الف) پس از هر عملیات، مقادیر `Front` و `Rear` را مشخص کنید.  
ب) وضعیت فیزیکی آرایه صف را در پایان رسم کنید.  
ج) آیا عملیات آخر موفق می‌شود؟ دلیل خود را توضیح دهید.  
د) شرط تشخیص پر و خالی بودن صف حلقوی را با استفاده از شمارنده عناصر و بدون شمارنده توضیح دهید.

## سؤال ۶ — لیست پیوندی (۲ نمره)

یک لیست پیوندی یک‌طرفه داریم:

```text
10 -> 20 -> 30 -> 40 -> 50 -> NULL
```

تابعی با مشخصات زیر طراحی کنید:

```cpp
Node* reverse(Node* head);
```

الف) الگوریتم معکوس‌کردن لیست را بدون استفاده از آرایه یا لیست کمکی توضیح دهید.  
ب) کد کامل C++ تابع را بنویسید.  
ج) نقش اشاره‌گرهای `prev`، `current` و `next` را توضیح دهید.  
د) پیچیدگی زمانی و فضای کمکی الگوریتم را تحلیل کنید.

## سؤال ۷ — بازگشت و Dynamic Programming (۲ نمره)

تابع زیر داده شده است:

```cpp
int mystery(int n) {
    if (n <= 1)
        return 1;

    return mystery(n - 1) + 2 * mystery(n - 2);
}
```

الف) مقدار `mystery(5)` را با رسم درخت بازگشت یا محاسبه مرحله‌ای به دست آورید.  
ب) رابطه بازگشتی زمان اجرا را بنویسید.  
ج) مرتبه زمانی آن را تحلیل کنید.  
د) تابع را با Dynamic Programming بهینه‌سازی کنید و پیچیدگی زمانی و فضایی نسخه جدید را به دست آورید.

## سؤال ۸ — Selection Sort و Insertion Sort (۲ نمره)

آرایه زیر داده شده است:

```text
[29, 10, 14, 37, 13, 25, 8]
```

الف) الگوریتم Selection Sort را به‌صورت صعودی اجرا کنید و آرایه را پس از هر گذر بنویسید.  
ب) تعداد مقایسه‌ها و جابه‌جایی‌های واقعی را محاسبه کنید.  
ج) همین آرایه را با Insertion Sort مرتب کنید و وضعیت آرایه را پس از هر مرحله نشان دهید.  
د) دو الگوریتم را از نظر پایداری، پیچیدگی زمانی و فضای کمکی مقایسه کنید.

## سؤال ۹ — Merge Sort (۲ نمره)

آرایه زیر را با الگوریتم Merge Sort مرتب کنید:

```text
[38, 27, 43, 3, 9, 82, 10, 15]
```

الف) تمام مراحل تقسیم آرایه را تا رسیدن به زیرآرایه‌های تک‌عضوی رسم کنید.  
ب) مراحل ادغام را به ترتیب نشان دهید.  
ج) رابطه بازگشتی زمان اجرای Merge Sort را بنویسید و حل کنید.  
د) فضای کمکی موردنیاز الگوریتم را تحلیل کنید.

## سؤال ۱۰ — طراحی الگوریتم (۲ نمره)

یک آرایه شامل \(n\) عدد صحیح داریم. هدف، یافتن دومین عدد بزرگ متمایز آرایه است.

مثال:

```text
Input:  [12, 45, 7, 45, 31, 20]
Output: 31
```

الف) الگوریتمی با پیچیدگی زمانی \(O(n)\) طراحی کنید.  
ب) کد کامل C++ آن را بنویسید.  
ج) آرایه‌ای که تمام عناصر آن برابر هستند بررسی کنید.  
د) درستی الگوریتم را با ناوردای حلقه توضیح دهید و پیچیدگی زمانی و فضای کمکی را به دست آورید.
