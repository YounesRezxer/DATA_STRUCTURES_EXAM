این فایل شامل راه‌حل مرحله‌به‌مرحله‌ی هر ۱۰ سؤال، فرمول‌ها، تحلیل پیچیدگی و کدهای C++ است.

## سؤال ۱ — تحلیل پیچیدگی

حلقه بیرونی مقادیر \(i=2^r\) را برای \(r=0,\ldots,\lfloor\log_2 n\rfloor\) می‌گیرد. برای یک مقدار ثابت \(i\)، حلقه دوم مقادیر \(j=1+qi\) را می‌گیرد.

اگر

\[
m_i=\left\lfloor\frac{n-1}{i}\right\rfloor+1
\]

باشد، تعداد اجرای حلقه سوم برای آن مقدار \(i\) برابر است با:

\[
S_i=\sum_{q=0}^{m_i-1}(1+qi)
=m_i+i\frac{m_i(m_i-1)}2
\]

چون \(m_i=\Theta(n/i)\)، داریم:

\[
S_i=\Theta(n/i+n^2/i)=\Theta(n^2/i)
\]

پس:

\[
T(n)=\Theta\left(\sum_{r=0}^{\lfloor\log_2 n\rfloor}\frac{n^2}{2^r}\right)
\]

با استفاده از مجموع هندسی:

\[
1+\frac12+\frac14+\cdots <2
\]

نتیجه:

\[
\boxed{T(n)=\Theta(n^2)}
\]

**نکته:** ضرب مستقیم تعداد تکرارها درست نیست، چون تعداد تکرار حلقه دوم به `i` و تعداد تکرار حلقه سوم به `j` وابسته است. در حلقه‌های وابسته باید مجموع‌گیری انجام شود.

## سؤال ۲ — آدرس‌دهی آرایه

آرایه `A[5][8]` دارای ۵ سطر و ۸ ستون است. آدرس پایه ۲۰۰۰ و اندازه هر عنصر ۴ بایت است. اندیس‌گذاری C++ از صفر آغاز می‌شود.

### الف) Row Major

فرمول عمومی:

\[
LOC(A[i][j])=Base+w[(i-LR)N+(j-LC)]
\]

در این مثال \(LR=LC=0\) و \(N=8\)، بنابراین:

\[
LOC(A[i][j])=2000+4(8i+j)
\]

### ب) آدرس A[3][6]

\[
LOC(A[3][6])=2000+4(8\times3+6)
\]

\[
=2000+4(30)=\boxed{2120}
\]

### ج) Column Major

در ذخیره‌سازی ستونی:

\[
LOC(A[i][j])=Base+w[(j-LC)M+(i-LR)]
\]

که \(M=5\) تعداد سطرهاست:

\[
LOC(A[3][6])=2000+4(6\times5+3)
\]

\[
=2000+132=\boxed{2132}
\]

### د) پیچیدگی دسترسی

آدرس عنصر با تعداد ثابتی عملیات حسابی محاسبه می‌شود و نیازی به پیمایش عناصر قبلی نیست:

\[
\boxed{T(n)=O(1)}
\]

## سؤال ۳ — Binary Search

آرایه:

`[3, 7, 11, 15, 19, 23, 27, 31, 35, 39]`

هدف: ۲۲

فرمول:

\[
mid=\lfloor(low+high)/2\rfloor
\]

| مرحله | low | high | mid | A[mid] | تصمیم |
|---|---:|---:|---:|---:|---|
| ۱ | 0 | 9 | 4 | 19 | چون 19 < 22، low=5 |
| ۲ | 5 | 9 | 7 | 31 | چون 31 > 22، high=6 |
| ۳ | 5 | 6 | 5 | 23 | چون 23 > 22، high=4 |

اکنون `low > high` است؛ پس عدد ۲۲ در آرایه وجود ندارد.

- تعداد بررسی عناصر آرایه: ۳
- Linear Search در این آرایه ناموفق، هر ۱۰ عنصر را بررسی می‌کند: ۱۰ مقایسه

| روش | بهترین حالت | بدترین حالت |
|---|---|---|
| Linear Search | \(O(1)\) | \(O(n)\) |
| Binary Search | \(O(1)\) | \(O(\log n)\) |

Binary Search به مرتب بودن داده نیاز دارد.

## سؤال ۴ — ارزیابی Postfix با Stack

عبارت:

```text
8 2 3 * + 12 4 / - 5 *
```

در هر عملگر، ابتدا عملوند دوم (`b`) و سپس عملوند اول (`a`) از پشته خارج می‌شوند؛ نتیجه `a op b` است.

| توکن | عملیات | پشته پس از عملیات |
|---|---|---|
| 8 | Push | [8] |
| 2 | Push | [8, 2] |
| 3 | Push | [8, 2, 3] |
| * | 2×3=6 | [8, 6] |
| + | 8+6=14 | [14] |
| 12 | Push | [14, 12] |
| 4 | Push | [14, 12, 4] |
| / | 12÷4=3 | [14, 3] |
| - | 14−3=11 | [11] |
| 5 | Push | [11, 5] |
| * | 11×5=55 | [55] |

پس:

\[
8+(2\times3)-(12/4)=11
\]

\[
11\times5=\boxed{55}
\]

### پیاده‌سازی عمومی C++ برای توکن‌های چندرقمی

```cpp
#include <iostream>
#include <sstream>
#include <stack>
#include <string>
#include <stdexcept>
using namespace std;

int evaluatePostfix(const string& expression) {
    stack<int> st;
    string token;
    stringstream ss(expression);

    while (ss >> token) {
        if (token == "+" || token == "-" ||
            token == "*" || token == "/") {

            if (st.size() < 2)
                throw runtime_error("Invalid postfix expression");

            int b = st.top(); st.pop();
            int a = st.top(); st.pop();

            if (token == "+") st.push(a + b);
            else if (token == "-") st.push(a - b);
            else if (token == "*") st.push(a * b);
            else {
                if (b == 0)
                    throw runtime_error("Division by zero");
                st.push(a / b);
            }
        } else {
            size_t pos = 0;
            int value = stoi(token, &pos);
            if (pos != token.size())
                throw runtime_error("Invalid token");
            st.push(value);
        }
    }

    if (st.size() != 1)
        throw runtime_error("Invalid postfix expression");

    return st.top();
}

int main() {
    string expression = "8 2 3 * + 12 4 / - 5 *";
    cout << evaluatePostfix(expression) << '\n';
}
```

اگر تعداد توکن‌ها \(n\) باشد:

\[
T(n)=O(n),\qquad S(n)=O(n)
\]

## سؤال ۵ — Circular Queue

ظرفیت \(N=6\) است. فرض می‌کنیم از شمارنده `count` استفاده می‌شود؛ در صف خالی `Front=Rear=-1` و پس از اولین درج هر دو صفر می‌شوند.

فرمول حرکت اندیس:

\[
( index+1 )\bmod 6
\]

| عملیات | Front | Rear | count |
|---|---:|---:|---:|
| شروع | -1 | -1 | 0 |
| Enqueue(10) | 0 | 0 | 1 |
| Enqueue(20) | 0 | 1 | 2 |
| Enqueue(30) | 0 | 2 | 3 |
| Enqueue(40) | 0 | 3 | 4 |
| Dequeue() | 1 | 3 | 3 |
| Dequeue() | 2 | 3 | 2 |
| Enqueue(50) | 2 | 4 | 3 |
| Enqueue(60) | 2 | 5 | 4 |
| Enqueue(70) | 2 | 0 | 5 |
| Enqueue(80) | 2 | 1 | 6 |

آرایه فیزیکی نهایی، با اندیس‌های صفر تا پنج:

| اندیس | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| مقدار | 70 | 80 | 30 | 40 | 50 | 60 |

ترتیب منطقی از Front:

`30, 40, 50, 60, 70, 80`

عملیات آخر موفق است و صف پس از آن پر می‌شود.

### تشخیص وضعیت صف

با شمارنده:

- خالی: `count == 0`
- پر: `count == N`

بدون شمارنده و با نگه‌داشتن یک خانه خالی:

- خالی: `Front == Rear` (بسته به قرارداد مقداردهی اولیه)
- پر: `(Rear + 1) % N == Front`

در روش خانه خالی، ظرفیت قابل استفاده \(N-1\) است. قرارداد دقیق `Front` و `Rear` باید در کل پیاده‌سازی یکسان بماند.

## سؤال ۶ — معکوس‌کردن Linked List

سه اشاره‌گر لازم داریم:

- `prev`: گره قبلی؛ ابتدا `nullptr`
- `current`: گره در حال پردازش؛ ابتدا `head`
- `next`: گره بعدی که پیش از تغییر پیوند ذخیره می‌شود

### کد C++

```cpp
struct Node {
    int data;
    Node* next;
};

Node* reverse(Node* head) {
    Node* prev = nullptr;
    Node* current = head;

    while (current != nullptr) {
        Node* next = current->next;
        current->next = prev;
        prev = current;
        current = next;
    }

    return prev;
}
```

مراحل:

```text
شروع:
10 -> 20 -> 30 -> 40 -> 50 -> NULL

پس از گام ۱:
10 -> NULL
20 -> 30 -> 40 -> 50 -> NULL

پس از گام ۲:
20 -> 10 -> NULL
30 -> 40 -> 50 -> NULL

پس از گام ۳:
30 -> 20 -> 10 -> NULL
40 -> 50 -> NULL

پس از گام ۴:
40 -> 30 -> 20 -> 10 -> NULL
50 -> NULL

پس از گام ۵:
50 -> 40 -> 30 -> 20 -> 10 -> NULL
```

هر گره یک‌بار پردازش می‌شود و تعداد اشاره‌گرهای کمکی ثابت است:

\[
\boxed{T(n)=O(n),\quad S(n)=O(1)}
\]

## سؤال ۷ — بازگشت و Dynamic Programming

تابع:

\[
f(n)=f(n-1)+2f(n-2)
\]

با شرایط پایه:

\[
f(0)=f(1)=1
\]

محاسبه:

\[
f(2)=1+2(1)=3
\]

\[
f(3)=3+2(1)=5
\]

\[
f(4)=5+2(3)=11
\]

\[
f(5)=11+2(5)=\boxed{21}
\]

### پیچیدگی نسخه بازگشتی

رابطه زمان:

\[
T(n)=T(n-1)+T(n-2)+O(1)
\]

معادله مشخصه بخش همگن:

\[
r^2-r-1=0
\]

ریشه غالب:

\[
\varphi=\frac{1+\sqrt5}{2}
\]

پس:

\[
\boxed{T(n)=\Theta(\varphi^n)}
\]

### نسخه بهینه با فضای ثابت

```cpp
int mysteryDP(int n) {
    if (n <= 1)
        return 1;

    int a = 1;
    int b = 1;

    for (int i = 2; i <= n; i++) {
        int c = b + 2 * a;
        a = b;
        b = c;
    }

    return b;
}
```

هر مقدار یک بار محاسبه می‌شود:

\[
\boxed{T(n)=O(n),\quad S(n)=O(1)}
\]

## سؤال ۸ — Selection Sort و Insertion Sort

آرایه اولیه:

`[29, 10, 14, 37, 13, 25, 8]`

### Selection Sort

در هر گذر، کمینه‌ی بخش مرتب‌نشده پیدا و با اولین عنصر همان بخش جابه‌جا می‌شود.

```text
Initial: [29, 10, 14, 37, 13, 25, 8]
Pass 1:  [8, 10, 14, 37, 13, 25, 29]
Pass 2:  [8, 10, 14, 37, 13, 25, 29]
Pass 3:  [8, 10, 13, 37, 14, 25, 29]
Pass 4:  [8, 10, 13, 14, 37, 25, 29]
Pass 5:  [8, 10, 13, 14, 25, 37, 29]
Pass 6:  [8, 10, 13, 14, 25, 29, 37]
```

تعداد مقایسه‌ها برای \(n=7\):

\[
C(n)=\frac{n(n-1)}2
\]

\[
C(7)=\frac{7\times6}{2}=\boxed{21}
\]

در این مثال، اگر فقط جابه‌جایی‌های واقعی (یعنی وقتی اندیس کمینه با اندیس ابتدای بخش فرق دارد) شمرده شوند، ۵ جابه‌جایی رخ می‌دهد. اگر جابه‌جایی خود عنصر با خودش نیز در کد شمرده شود، شمارنده‌ی swap ممکن است متفاوت باشد.

### Insertion Sort

```text
Initial: [29, 10, 14, 37, 13, 25, 8]
Pass 1:  [10, 29, 14, 37, 13, 25, 8]
Pass 2:  [10, 14, 29, 37, 13, 25, 8]
Pass 3:  [10, 14, 29, 37, 13, 25, 8]
Pass 4:  [10, 13, 14, 29, 37, 25, 8]
Pass 5:  [10, 13, 14, 25, 29, 37, 8]
Pass 6:  [8, 10, 13, 14, 25, 29, 37]
```

| ویژگی | Selection Sort | Insertion Sort |
|---|---|---|
| بهترین زمان | \(O(n^2)\) | \(O(n)\) |
| میانگین زمان | \(O(n^2)\) | \(O(n^2)\) |
| بدترین زمان | \(O(n^2)\) | \(O(n^2)\) |
| فضای کمکی | \(O(1)\) | \(O(1)\) |
| پایداری نسخه معمول | ناپایدار | پایدار |

## سؤال ۹ — Merge Sort

آرایه اولیه:

`[38, 27, 43, 3, 9, 82, 10, 15]`

### تقسیم

```text
[38,27,43,3,9,82,10,15]
          /       \
    [38,27,43,3] [9,82,10,15]
      /    \       /    \
  [38,27] [43,3] [9,82] [10,15]
   / \     / \    / \    / \
 [38][27][43][3][9][82][10][15]
```

### ادغام

```text
[27,38] [3,43] [9,82] [10,15]

[3,27,38,43] [9,10,15,82]

[3,9,10,15,27,38,43,82]
```

### تحلیل

در هر سطح، مجموع هزینه ادغام \(\Theta(n)\) است و تعداد سطوح \(\Theta(\log n)\) است:

\[
T(n)=2T(n/2)+\Theta(n)
\]

طبق قضیه مستر:

\[
a=2,\quad b=2,\quad f(n)=\Theta(n)
\]

\[
n^{\log_ba}=n
\]

پس:

\[
\boxed{T(n)=\Theta(n\log n)}
\]

در پیاده‌سازی آرایه‌ای متداول، آرایه کمکی فضای \(\Theta(n)\) می‌گیرد؛ عمق پشته بازگشتی نیز \(\Theta(\log n)\) است. بنابراین فضای کمکی کل همچنان:

\[
\boxed{S(n)=\Theta(n)}
\]

## سؤال ۱۰ — دومین عدد بزرگ متمایز

هدف، یافتن دومین مقدار بزرگ است؛ تکرار مقدار بیشینه نباید به‌عنوان دومین مقدار شمرده شود.

### کد مقاوم C++

```cpp
#include <iostream>
using namespace std;

bool secondLargestDistinct(const int A[], int n, int& answer) {
    if (n < 2)
        return false;

    int largest = 0;
    int second = 0;

    bool hasLargest = false;
    bool hasSecond = false;

    for (int i = 0; i < n; i++) {
        if (!hasLargest || A[i] > largest) {
            if (hasLargest) {
                second = largest;
                hasSecond = true;
            }

            largest = A[i];
            hasLargest = true;
        }
        else if (A[i] != largest &&
                 (!hasSecond || A[i] > second)) {
            second = A[i];
            hasSecond = true;
        }
    }

    if (!hasSecond)
        return false;

    answer = second;
    return true;
}

int main() {
    int A[] = {12, 45, 7, 45, 31, 20};
    int n = sizeof(A) / sizeof(A[0]);

    int answer;

    if (secondLargestDistinct(A, n, answer))
        cout << answer << '\n';
    else
        cout << "No second distinct maximum\n";
}
```

خروجی:

```text
31
```

برای آرایه‌ای مانند `[5, 5, 5, 5]` مقدار دوم متمایز وجود ندارد و تابع `false` برمی‌گرداند.

### اثبات با ناوردای حلقه

پس از پردازش هر پیشوند آرایه:

1. `largest` بزرگ‌ترین عنصر دیده‌شده است.
2. اگر `hasSecond` درست باشد، `second` دومین عنصر بزرگ متمایز دیده‌شده است.

در هر تکرار، اگر عنصر جدید از بزرگ‌ترین مقدار بزرگ‌تر باشد، بیشینه قبلی به جایگاه دوم منتقل می‌شود. در غیر این صورت، اگر با بیشینه برابر نباشد و از مقدار دوم بزرگ‌تر باشد، مقدار دوم به‌روزرسانی می‌شود.

پس از پردازش تمام عناصر، مقدار دوم بزرگ متمایز کل آرایه در `second` قرار دارد.

هر عنصر یک بار بررسی می‌شود:

\[
\boxed{T(n)=O(n)}
\]

تعداد متغیرهای کمکی ثابت است:

\[
\boxed{S(n)=O(1)}
\]
